# DreamGlows — Pitch

> Pitch reviewed: 2026-09-02 · Project state: see canonical sources below

DreamGlows helps people turn a concrete dream or ambition into visible progress through the chain dream → milestone → task → progress. It keeps long-term purpose connected to the next achievable action without reducing the experience to generic task management.

## Current state

The Obsidian plugin is the first active surface; website, Chrome, Windows, and Android surfaces are being aligned progressively around the same product language.

## Boundaries

DreamGlows structures progress but does not guarantee that a dream will be achieved; calendar or external integrations require explicit privacy decisions.
